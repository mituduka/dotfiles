# tmux の使い方

設定ファイルは `~/.config/tmux/tmux.conf` に置いてある。prefix は `Ctrl-b` ではなく `Ctrl-j` に変えてある。以下の表では、prefix を押してから次のキーを押すことを `prefix + x` と書く。

## セッション

tmux の利点は、接続が切れてもセッションが残ることにある。SSH が落ちても作業は続いている。

```sh
tmux                     # 新しいセッションを開始
tmux new -s work         # 名前を付けて開始
tmux ls                  # セッション一覧
tmux a                   # 直前のセッションに再接続
tmux a -t work           # 名前を指定して再接続
tmux kill-session -t work
```

| キー | 動作 |
| --- | --- |
| `prefix + d` | デタッチ (セッションは生きたまま抜ける) |
| `prefix + s` | セッション一覧から選ぶ |
| `prefix + $` | セッション名を変更 |

## ウィンドウ

ウィンドウはタブにあたる。番号は 1 から始まり、閉じると自動で詰められる。

| キー | 動作 |
| --- | --- |
| `prefix + c` | 新規ウィンドウ |
| `prefix + Ctrl-h` | 前のウィンドウへ |
| `prefix + Ctrl-l` | 次のウィンドウへ |
| `prefix + <数字>` | 番号で直接移動 |
| `prefix + ,` | ウィンドウ名を変更 |
| `prefix + &` | ウィンドウを閉じる |

`Ctrl-h` と `Ctrl-l` はリピートが効くので、prefix を押し直さずに連打できる。

## ペイン

ペインは画面分割にあたる。分割したペインは、元のペインのカレントディレクトリを引き継ぐ。

| キー | 動作 |
| --- | --- |
| `prefix + \|` | 垂直に分割 (左右に並ぶ) |
| `prefix + -` | 水平に分割 (上下に並ぶ) |
| `Alt + 矢印` | prefix 不要でペイン間を移動 |
| `prefix + z` | ペインを一時的に最大化 / 戻す |
| `prefix + x` | ペインを閉じる |
| `prefix + {` / `}` | ペインの位置を入れ替える |
| `prefix + Space` | レイアウトを切り替える |

マウスも有効にしてあるので、ペインの選択やリサイズ、スクロールはマウスでもできる。

`Alt + 矢印` が効かないときは[うまく動かないとき](#うまく動かないとき)を見てほしい。prefix を経由してもかまわないなら、tmux 既定の `prefix + 矢印` でも移動できる。こちらはリピートが効くので、prefix を一度押したあとは矢印を連打するだけでよい。

## コピーモード

| キー | 動作 |
| --- | --- |
| `prefix + [` | コピーモードに入る (スクロールバック閲覧) |
| `Space` | 選択開始 |
| `Enter` | コピーして抜ける |
| `q` | 抜ける |
| `prefix + ]` | 貼り付け |

## ステータスバーの見方

左端にセッション名、中央にウィンドウの一覧、右端に状態が並ぶ。表示は 5 秒ごとに更新する。

```
 work │ zsh │ vim │            [prefix] ok  85% hostname  2026-09-13 12:00
  ↑     ↑                          ↑     ↑   ↑     ↑            ↑
セッション ウィンドウ           prefix 待機 疎通 電池 ホスト名    日時
```

| 表示 | 意味 |
| --- | --- |
| prefix インジケータ | prefix を押した状態のときだけ点灯する |
| `ok` / `offline!` | ネットワークの疎通状態 |
| 電池残量 | バッテリーの無いサーバでは空欄になる (表示は崩れない) |
| ホスト名 | SSH で複数のサーバを渡り歩くときに今どこにいるかが分かる |

## プラグイン

プラグインは TPM が管理する。最初の導入は chezmoi のスクリプトが対話なしで済ませるので、`prefix + I` を押す必要はない。

| プラグイン | 役割 |
| --- | --- |
| `tmux-battery` | バッテリー残量 |
| `tmux-online-status` | ネットワークの疎通 |
| `tmux-prefix-highlight` | prefix 待機状態の表示 |
| `tmux-resurrect` | セッション構成の保存と復元 |
| `tmux-continuum` | resurrect の自動保存 |

プラグインを足したり減らしたりしたときは、次のキーで操作する。

| キー | 動作 |
| --- | --- |
| `prefix + I` | プラグインリストに追加したものを導入 |
| `prefix + U` | プラグインを更新 |
| `prefix + Alt-u` | リストから消したプラグインを削除 |

### セッションの保存と復元

| キー | 動作 |
| --- | --- |
| `prefix + Ctrl-s` | 現在の構成を保存 |
| `prefix + Ctrl-r` | 保存した構成を復元 |

continuum が 15 分ごとに自動で保存している。一方、自動での復元は無効にしてあるので、再起動したあとは `prefix + Ctrl-r` を自分で押す。tmux の起動と同時に復元させたければ、次の 1 行を `tmux.conf` に足す。

```tmux
set -g @continuum-restore 'on'
```

## 設定を変える

ソース側を編集して反映する。

```sh
chezmoi edit ~/.config/tmux/tmux.conf
chezmoi apply
```

`tmux.conf` を変更すると、chezmoi が TPM のインストーラを自動で走らせる。`run_onchange_after_30-tmux-plugins.sh` が `tmux.conf` のハッシュを見ているからで、プラグインを足したときに `prefix + I` を押さなくてよいのもこれが理由である。

起動中の tmux に設定を読み直させたいときは `prefix + r` を押す。

`status-interval` は 5 秒にしてある。もっと短くしたくなっても、1 にはしないほうがいい ([design.md](design.md#tmux-の-status-interval-を-1-にしない))。

## うまく動かないとき

### Alt + 矢印でペインが移動しない

macOS では Option キーが Alt にあたるが、端末側の設定と既定のキーバインドに阻まれて、tmux まで届かないことがある。上下だけ動いて左右が動かないという症状も含めて、Ghostty での対処は [design.md](design.md#ghostty-の-option--矢印) に書いた。

### 色が出ない、崩れる

`default-terminal` には `tmux-256color` を指定し、truecolor は `terminal-overrides` の `Tc` で有効にしている。外側の端末が truecolor に対応していなければ、そのぶん色は落ちる。

```sh
echo $TERM               # tmux の中では tmux-256color になる
tmux info | grep Tc      # truecolor が有効か
```

### 記号が □ になる

これは tmux ではなくフォントの問題なので、ターミナル側で HackGenConsoleNF が選ばれているかどうかを確認する。
